= K9 Contracts — JuliaPackageSpitter.jl

This directory contains the K9 self-validating contracts (`application/vnd.k9+nickel`) for `JuliaPackageSpitter.jl`:

* `project-metadata.k9.ncl` (`'Kennel` — pure data): canonical package identity, ADR-008 Profile C UUIDv8 (`81dd1219-803c-8eeb-85ea-39cf86282952`), Julia compatibility floor (`1.10`), exported API (`PackageSpec`, `generate_package`), and verification artifact paths.
* `ci-validation.k9.ncl` (`'Yard` — Nickel validation contracts): CI matrix (`1.10`, `1.11`), `JuliaFormatter` style (`'DefaultStyle`), strict dogfood validation, pinned container base digests, and Agda-proved package identity gates.

== Validation

Validated in CI by `.github/workflows/dogfood-gate.yml` (`hyperpolymath/k9-ecosystem/validate-action` with `strict: 'true'`) and locally via:

[source,bash]
----
nickel typecheck .machine_readable/svc/k9/project-metadata.k9.ncl
nickel typecheck .machine_readable/svc/k9/ci-validation.k9.ncl
----
