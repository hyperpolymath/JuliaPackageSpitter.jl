# gate.

# The register itself, so that the rule can state what it forbids.
docs/naming/retired-names.txt
# The allowlist, so a reviewer can see what is exempt without opening the gate.
docs/naming/retired-names-allowlist.txt
# The changelog: a rename that is not in the changelog did not happen.
CHANGELOG.adoc
# The decision record that retired the name, with its evidence.
docs/decisions/0002-reconcile-repository-and-package-name.adoc
# The Agda module generated from the register, which proves each retired name
# could never have been a Julia package name. The characters of the retired
# names appear here as data.
proofs/agda/RetiredNames.agda
# The proof gate's own documentation, which quotes the retired name to explain
# what the negative controls reproduce.
proofs/agda/README.adoc
# The negative control that reproduces the pre-rename defect. Its comment names
# the retired repository so a reader knows what the fixture is a recording of;
# the claim itself is built from RetiredNames.retiredName1, not retyped.
tests/reject/MismatchedRepoName.agda
