# Retired names for this repository.
#
# One name per line. Blank lines and lines beginning '#' are ignored. A retired
# name must not reappear anywhere in the tracked tree, except in the files listed
# in retired-names-allowlist.txt (the historical record: the changelog, the ADR
# that retired it, and this register).
#
# What this file holds. Every entry is a name PROVED impossible as a Julia
# package identifier: proofs/agda/RetiredNames.agda (generated from this file by
# scripts/gen-identity-agda.sh --mode retired) refutes each entry by showing that
# it contains a character a Julia identifier may not contain ('-' or '.'). An
# entry that is a legal identifier cannot be registered, and the generator
# refuses it. That is the reason a spelling such as JULIAPACKAGE_REUSE_AUDIT
# (underscores and upper case are legal identifier characters) is NOT listed
# here: it could have been a package name, so the proof would be false.
#
# What tree hygiene covers. Hygiene is a different rule and it is wider. The
# checker tests/check-identity.sh (section retired-names) takes each entry above
# and matches it in EVERY spelling: hyphen, space, underscore, title case, upper
# case, the ".jl" suffix dropped, the separators dropped, or a line break in the
# middle of the name. So a legal-identifier rendering such as
# JULIAPACKAGE_REUSE_AUDIT is still a finding in the tree, even though it is not
# a register entry. The register says what is impossible; the checker says what
# must not appear.
#
# Enforcement is mechanical, not editorial:
#   * tests/check-identity.sh   greps the tree (every spelling, across line
#                               breaks) and fails on any hit outside the
#                               allowlist;
#   * tests/check-identity-fixtures.sh   proves the checker rejects each spelling
#                               family in a deliberately broken tree;
#   * proofs/agda/RetiredNames.agda (generated from this file by
#     scripts/gen-identity-agda.sh --mode retired) proves that each name below
#     could never have been a legal Julia package name, which is why it was
#     retired rather than adopted.
#
# Retired 2026-10-04 by the decision recorded in
# docs/decisions/0002-reconcile-repository-and-package-name.adoc: the repository
# was named for a "reuse audit" capability that is still unimplemented roadmap
# work (ROADMAP.adoc, v0.3.0), while the package it contains, the README, the
# repository description and the registry entry all describe a scaffolder.
